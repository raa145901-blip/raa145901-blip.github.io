## Порядок загрузки
1. Распаковать архив.
2. Проверить, что загружаются папки `moscow`, `spb` и корневой `index.html`.
3. GitHub → репозиторий → Add file → Upload files → Commit changes.
4. Проверить 3 страницы и наличие `114702822` в исходном коде.
5. Проверить, что `/card/` и скачивание VCF продолжают работать.
6. Не отправлять страницы на повторный переобход в Яндексе до проверки публикации; переобход при необходимости делать после проверки.
